## 服务器流程

1. 网络接通后验证主机与 GPU，保留现有进程，选空闲 GPU；不自动抢占其他任务。
2. 上传已提交源码包和已校验数据。记录 Python/PyTorch/CUDA、GPU、源码提交和数据哈希。
3. 使用 `tools/server_preflight_j02.py` 生成服务器专用协议，冻结主机名、GPU 和最多 3600 秒单次运行上限。实际 GPU 试运行与性能仍须在服务器检查；本机只验证语法和导出逻辑，不宣称 CUDA 已验证。
4. 在独立目录运行四组×三 seed；预算为 22,500 次新矩阵更新，单配置单 seed 最多 2000 次（包含共享预训练的归属）。用户迁移前的 100 次计时、500 次预训练、2000 次监督训练和至少 1500 次已观察到的联合训练另行记录。
5. 运行结束后应用冻结门槛，复算指标，保存所有失败结果。若科学门槛失败，按原目标停止候选分支，不启动 J-02C/P-01；若通过，继续独立确认阶段。
