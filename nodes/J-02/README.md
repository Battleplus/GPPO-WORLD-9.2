# J-02：变化表示与局部动作条件——设计草案，尚未训练

J-01 已完成，但表示预测未超过持久化基线，探针落后于监督图预测器及随机表示，因此暂停下游 GPPO 接入。以下只是下一轮假设和决策顺序，不是补做 J-01 来提高已公布分数。

1. **先保留有效对照。** 保留原始 GPPO、原 EAWM、监督图预测器、随机表示和无动作 JEPA；后两者是识别“表示训练是否真的有用”的必要对照。
2. **优先研究变化，而非只预测全局表示。** 尝试预测 EMA 编码的未来/当前表示差，并明确是否使用残差捷径。必须分别比较当前表示直接持久化、只用动作、无动作及完整版本，防止捷径掩盖无效动力学。
3. **让动作对应到图中的执行位置。** 当前 J-01 使用固定动作编号。候选升级把实际 UAV–Region 端点和相关边特征输入预测器，比较局部节点预测与全局均值池化；不能改变真实 mask 或候选边身份。
4. **事件信息与历史分阶段加入。** 先用已有因果字段，不要求用户额外提供完整物理方程；加入短历史、当时已到达证据、自动事件监督时分别消融。自动事件标签可由训练转移离线生成，但未来事件只能作为监督目标。若加入事件/状态/奖励监督，命名为 JEPA 混合模型，不再称纯自监督 JEPA。GES 必须在独立事件消融之后再讨论。
5. **重新冻结独立协议。** 为 J-02 单独创建 Train/Validation/Test。J-01 Test 只作已知诊断，不能用于新门槛或超参选择。先在新的开发集比较，再固定三 seed 预算、目标/动作定义、读出任务与最小效应阈值；封存后一次性新 Test 验证。门槛失败不追加训练挑最好的一次。
6. **下游 GPPO 仍然有门槛。** 表示质量达标后，单独设计冻结解码头、不确定度与 OOD/超时回退校准，先只读 Shadow，再与原 GPPO/历史基线做同预算策略实验。不得复用 EAWM 校准参数为 JEPA 背书。

GPU 服务器适合下一轮更长历史、更大数据或策略训练；是否使用取决于冻结后的预算，本节点当前没有服务器任务或后台训练。
