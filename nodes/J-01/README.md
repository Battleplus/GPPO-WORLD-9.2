# J-01：动作条件 Graph-JEPA 独立实验

目标：先验证图表示是否包含可读出的未来变化及动作信息，再决定是否值得接入 GPPO。J-01 不替换 EAWM，不执行 T-06，也不将表示损失下降当作策略收益。

## 方法与边界

输入是决策时可见的异构图、已到达的证据摘要和本次动作编号。在线编码器生成当前表示，动作条件预测器生成下一步表示；未来图只交给停梯度的 EMA 目标编码器。预测器不是动作选择器，GPPO 仍然负责选动作。

此版本只验证一步预测，没有循环历史、视频 patch 掩码或视频预训练。它是 JEPA 思想的图迁移，不是官方模型复现。额外加入在线表示的方差/协方差约束，以显式监测并抑制塌缩；约束不保证一定成功。

依据：[I-JEPA 官方训练实现](https://github.com/facebookresearch/ijepa/blob/main/src/train.py)中的冻结目标编码器、停梯度目标和优化后 EMA 更新；[V-JEPA 2 官方介绍](https://ai.meta.com/blog/v-jepa-2-world-model-benchmarks/)中的动作条件未来预测；[VICReg 论文](https://arxiv.org/abs/2105.04906)的方差/协方差防塌缩思想。没有复制这些仓库的模型代码或权重。

## 预先冻结的实验

详见 [protocol.json](protocol.json)。动作 JEPA、无动作 JEPA、监督图预测器，各训练三个 seed、60 个 epoch，统一小批次与顺序；只保留最终模型用于比较，不挑最佳 seed/epoch。监督对照使用相同图编码器和预测器，加一个监督解码器，参数量单独报告，不声称精确参数匹配。另报告未训练随机初始化表示的只读探针。

新数据覆盖七类场景、三种行为策略，同一事件带的三种策略轨迹只能处于一个数据分区。训练/验证/测试分别每类 8/4/4 条事件带，共 336 个 episode。旧 T01 数据仅提供已经训练好的 512 步 GPPO 行为采样器；旧测试轨迹不得用于此次训练或阈值调整。数据保留原始图节点与边、决策版本、动作执行信息和 tape，完整材料放入版本化 Release。

统一线性探针只读取预测的未来表示，训练集拟合，验证集从固定 ridge 网格选择，所有模型和探针冻结后一次性测试。报告状态增量、奖励、各项代价及延续信号的标准化误差，也报告原始单位误差；状态主指标使用训练集中有变化的维度，防止大量常数维度淹没误差。对照之间不比较各自表示空间的原始 JEPA loss。

动作敏感性在每个模型自身的目标表示空间比较真实动作与合法替代动作，按事件带聚类 bootstrap；它不能证明替代动作在环境中真实会产生什么后果。另比较当前目标表示直接持久化。塌缩指标使用均值标准差和有效秩。

## 决策规则

预设门槛是本项目的探索性预算门槛，不是论文定理。任一门槛失败：保留全部负结果，停止投入下游 GPPO 训练。全部通过也仅允许考虑新的接入方案，仍须校准只读解码头、不确定度与安全回退，不能套用 EAWM 的校准或声称 GPPO 已提升。
