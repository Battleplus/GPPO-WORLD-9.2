# M-10 限制与禁止扩大

- 当前环境是归一化仿真，不是飞控、网络或真实动力学验证。
- 4 UAV、6 任务槽、25 动作和 18 时间单位是本轮冻结协议，不能外推到竞赛规模。
- 两类型与五类型是同一可见数据的两种编码视图。五类型结果不等于已经取得五类真实资产。
- MLP、图和历史策略共享动作、mask、可见遥测和训练预算。三 seeds 的结果支持比较记录，不支持稳定增益结论。
- 世界模型预测 context 已被融合策略实际消费。world context 没有带来完成数提升，event trigger 也没有显示提升。
- event trigger 阈值 0.5 的初始矩阵产生 0 次触发；阈值 0.2 的补充矩阵产生约 5 次/episode。阈值调整不是盲态最终评估，应保留为敏感性结果。
- timeout 的 Shadow 合同仍是推理后门禁，不是硬取消；服务器两个历史 timeout 测试通过只说明该环境下重跑通过。
- OOD、能量拒绝、损毁和通信故障在仿真事件合同中验证，不能替代真实分布漂移或链路测试。
- 返航、换电和充电范围待用户确认。本轮继续保留问题，没有自动排除，也没有声称已实现。
- 尚未完成 GPPO-History 与真实旧模型公平对照、长预算稳定性、完整五类型公平矩阵、真实控制周期和导师评审。
