# M-10-R 限制与未完成项

- 本轮闭环证明了修正后的代码路径、训练真实更新和公平协议执行，不证明某一策略稳定优于另一策略，也不等同完整会议研发完成。
- Graph-5 是本轮显式 UAV/Region/Target/Task/Event 表示与 UAV–Task 关系编码的会议对照实现；它仍是归一化仿真图，不是实际飞行系统的完整语义资产。
- 3 个训练 seed、2048 steps 和 5 个评估 tape 的统计不确定性有限；不能只选最佳 seed 或 checkpoint。
- 触发组的 217 次评估触发全部由 public_event 记录；模型风险阈值虽由 validation F1 选择，但没有形成生产级误触发/漏触发优化结论。旧 context gating 和阈值敏感性结果保留且不改名。
- 世界模型 test 指标与简单 baseline 同时保存；OOD 为冻结合成集合。尚未验证真实链路异常、网络超时和分布漂移下的生产保障。
- latency 是服务器上的 CPU/CUDA 归一化仿真测量，未包含实际飞控、无线传输和未知控制周期，不能宣称实时竞赛合格。
- 返航、换电、充电的最低验收范围，真实任务规模、控制周期和汇报日期仍待确认；本轮没有擅自缩减为已排除。
- 群发、彩排、导师实际评审属于用户后续执行事项，不冒充本轮完成。
