# M-10 历史问答底稿（保留）

> 当前总验收请使用 `m10-final-acceptance-qa.md`。以下内容保留历史阶段记录，不能替代当前 R3 预测基线、触发负结果和候选冻结口径。

**为什么不继续训练到看起来更好？**

本轮先冻结语义和公平预算。继续调参会把测试选择和模型收益混在一起。当前结果已经保存负结果，下一轮应先确认返航/换电/充电范围和竞赛控制周期。

**五类型版本在哪里？**

本轮 five-type 是同一可见 UAV/Task 信息的五角色编码视图，不代表已经拥有缺失的真实五类型资产。真实五类型公平资产仍是缺口。

**能量规划是否由策略学会？**

策略只看到收到的能量遥测。能量耗尽、拒绝和扣费由执行层与 ServiceClock 计算；本轮不能宣称策略学会了完整能量规划。

**世界模型是否提升回报？**

没有稳定证据。Graph-PPO + world context 的 return 均值 31.000，event trigger 为 30.956，完成数都为 4.000；三 seed 区间不足以支持增益结论。

**为什么 CPU 比 GPU 更快？**

当前模型和输入很小，GPU 启动和同步开销占比高。CPU/GPU 测量是本机本协议结果，不是硬件普遍规律。

**事件触发为什么有两套阈值？**

0.5 的第一矩阵出现 0 次触发，作为负结果保留。0.2 的补充矩阵用于检查触发敏感性，不能把后者写成预注册的无偏选择。

**当前离实际竞赛部署还差什么？**

还需要真实通信与飞行动力学、返航/换电/充电决策、竞赛规模和控制周期确认、完整五类型公平比较、长时间多 seed 稳定性、安全审计和人工评审。
