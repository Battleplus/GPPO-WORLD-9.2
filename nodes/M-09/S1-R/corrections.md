# S1-R 修正项与旧结论处理

| 缺陷 | 修正 | 旧结论处理 |
|---|---|---|
| `terminated` 被当作完成 | 用真实任务状态分类 | 旧版 60/60 完成率收窄为“episode 结束且状态清空”，不再作为功能通过证明 |
| stale 重试绕过能量入口 | 初次/重试共用 EnergyLedger | 旧版能量/重试结论仅保留为历史结果，执行约束结论以 S1-R 为准 |
| 能量扣费使用旧端点 | 只按实际接受动作的 `charged_uid` 扣费 | 旧扣费轨迹不再作为当前证据 |
| 重分配包含首次分配 | 前后关系变化并排除 initial map | 旧重分配汇总撤回，改用逐 trace 计数 |
| 低置信度只看事件名/payload | 检查确认集合、发生/可见/决策时序 | 复合三因素“通过”撤回 |
| 未来输入只扫描字段名 | 白名单加实际暴露事件时序 | UAV 损毁与复合场景标记失败 |
| 人工 probe 混入策略结果 | 独立 execution-layer-probes | 自主策略完成率不含 probe |

S1-R 的 blocked 状态来自真实固定 tape 证据，不通过替换 tape、调阈值或重新训练规避。
