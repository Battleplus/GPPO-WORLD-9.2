# 优化报告

## 采用：GraphActorCritic inference mode

测量热点是策略前向。将三类型 `GraphActorCritic.act` 的 `@torch.no_grad()` 替换为 `@torch.inference_mode()`，不改模型权重、输入维度、动作空间、mask、确认、安全、能量、版本或日志语义。优化提交保存在隔离基线 `e3f2b4053446e8fe4ba8787c6c1b4be0910ced25`，补丁 SHA-256 为 `8613b8c9999b950495813373adb1efa8954121876820e5814cbf6c778a4f2e66`。

服务器 source-act 配对结果（60 个 tape 组，5 次重复按 tape 聚合）：

- CPU：端到端均值 `4.277103 → 4.150364 ms`，差值 `-0.125207 ms`（`-2.927%`，95% tape-group CI `[-0.135745,-0.114669]`）；纯策略段 `2.197379 → 2.106029 ms`（`-4.119%`）。
- `cuda:0`：端到端均值 `5.673699 → 5.489172 ms`，差值 `-0.186646 ms`（`-3.290%`，95% tape-group CI `[-0.203170,-0.170122]`）；纯策略段 `3.075608 → 2.927091 ms`（`-4.873%`）。

区间均不跨 0，且结果不依赖挑选最快重复；因此采用这一项。没有实施第二项优化：graph 缓存、日志裁剪和结构重构均未有足够测量或会扩大语义风险。

## 未验证结论

会议所称“五类型图比 PPO 慢 3～4 倍”没有同条件五类型模型、普通 PPO checkpoint、配置和 workload，S2 不作该结论。两类型重构同样缺少可复现实验资产。
