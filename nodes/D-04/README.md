新一轮建议把“全部实际决策奖励之和”作为与 PPO 训练一致的主指标，同时强制报告旧事件归因 return、fixed J 和失败率。该建议源于指标语义核查，属于新的前瞻性设计，不能用来撤回旧 T-05 的负结果。
