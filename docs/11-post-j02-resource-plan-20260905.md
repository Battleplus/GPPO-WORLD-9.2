## 当前结论与目标边界

上一轮目标已在“有证据的候选失败终止点”完成，但原始项目目标中的独立 GPPO-History 对照、稳定策略收益仍未完成。下一轮应先定位任务信息损失，再确定是否值得训练新世界模型；历史策略对照另设独立节点，不能把旧候选失败解释为整个项目研究结束。

J-fixed-action 三 seed 的潜变量持久化改善为 92.43%、88.08%、88.19%，但 reward NMSE 为 0.5054、0.4653、0.4564，监督 S 为 0.0381、0.0369、0.0347。说明“潜变量预测准确”不足以推出“任务预测准确”。这不单独证明编码器失效，也可能涉及目标信息缺失、读出结构和预测器误差。

代码中任务标签包含 commit 减 pre 的状态增量、即时 reward/cost；当前候选读出只输入预测 commit latent。因此需要补齐带 pre/动作条件的 oracle 诊断：仅给真实 commit 编码，未必足以恢复状态差分或提交过程奖励，不能把它当成所有任务的理论上界。

## 执行顺序

### 1. R-03：固定模型的信息与读出诊断

复用三个 seeds 的终点模型，保持权重不变。在同一 Train 上拟合、同一已使用 Validation 上评价以下视角，全部标记为事后探索性诊断：

1. 当前编码 + 当前动作/证据；预测 commit 编码；当前编码 + 预测 commit 编码 + 当前动作/证据。
2. 当前编码 + 真实 commit 的同一冻结编码 + 当前动作/证据，仅作离线 oracle。
3. 原始 pre + 动作/证据直接读出；原始 pre + 真实 commit + 动作/证据，仅作原始信息 oracle。
4. 与训练目标一致的监督组原生 decoder 和统一 ridge 分别报告，区分监督模型本体与后拟合读出。

先用固定 ridge=1，不搜索超参。宽度不同的输入报告特征维度和参数量，并补共同宽度的固定投影敏感性检查，不能宣称天然等容量。输出逐 seed、场景、tape、状态字段、历史有效长度的误差，以及合法分支排序和后悔；同一 seed/tape 成对比较。

拟定资源上限：不训练 backbone；最多 120 个预列线性读出，单次服务器任务墙钟 1 小时。若线性结果无法区分读出瓶颈，才另外冻结小 MLP 诊断协议，不临场搜索到通过。所有拟合均在服务器执行。

决策依据：若条件 oracle 也差而原始信息 oracle 好，优先修表示/可读性；若条件 oracle 好、预测视角差，优先修预测器；若加入当前信息后改善，优先研究条件残差读出；若原始直接读出已充分，优先验证其决策价值。上述是机制线索，不是确定因果归因，也不用于撤销 J-02 失败。

### 2. D-05：数据和任务可识别性审计

统计独立 tape、动作端点、NOOP/单合法动作比例、短历史、稀有成本及事件支持。检查相同可见输入是否对应不同 commit 后果，明确不可观测性；用原始执行逻辑审查即时奖励是否主要由已知规则决定，不复制简化环境替代真实标签。

先审计现有数据，无新增模型更新。仅当覆盖不足已定位时，另行冻结最多 140 个新开发 tapes（七场景各 20）、三种行为策略及完整分支 split 归属。新开发种子不得与历史数据冲突，不能将已查看 Validation 政名为新 Test。风险违例仍无正例时继续标不可评估，不降低执行安全机制制造样本。

### 3. J-03：由诊断选择一个新机制

候选优先级：条件读出/任务充分表示；其后才是任务辅助的混合 JEPA。加入状态、奖励或成本监督时明确命名为混合模型，并单列标签成本。更大模型、更长 rollout、事件头和 GES 暂不捆绑到一次改动中。

至多三个配置 × 三个新 seeds：强监督参照、根据 R-03 选定的单一新机制、对应的单因素消融。每配置每 seed 最多 2000 更新，含预训练，总归属上限 18000；先冻结再训练。计时试跑单列，建议最多 100 更新；墙钟上限先设 2 小时，按实测缩小而非自动延长。

J-02 全矩阵 22500 更新实测约 23 分钟，可作为同等规模的量级参考；数据和结构改变后必须重新计时。数据扩展或多卡不会自动提高科学可信度。

验收沿用明确的任务误差、动作消融、防塌缩和合法分支质量要求，但作为新协议在看新候选分数前冻结；建议保留相对监督/原始直接读出不超过 1.10 的界限与至少 5% 动作消融改善。失败则封存，不追加挑选。成功才讨论独立确认数据，不能直接宣称策略收益。

### 4. P-00：独立补齐 GPPO-History

将原始要求缺口拆成独立基线研究，不属于失败 J-02 候选接入。比较从头训练的 GPPO 与 GPPO-History，输入、奖励、真实交互预算、安全链一致；历史窗口初设 K=4，报告参数量并考虑容量匹配参照。

建议先工程 pilot：两组 × 三 seeds × 10000 接受决策，共 60000；这是拟议预算，不是已启动任务。只用于接口、训练稳定性和耗时估计，不能用 pilot 最佳模型作正式结果。正式阶段再冻结五 seeds、独立新 Test、主指标及统计方案。P-01 的世界模型增量实验继续要求候选质量过关。

### 5. 归档与推进控制

先补 R-02 原始证据的独立 Release 和引用入口；将本规划推送至执行分支，后续通过可审查变更更新 main 的状态入口。不要将仓库设置为只读 archived。

新任务执行前重连服务器，检查 GPU 进程、磁盘、环境及数据哈希。默认单卡；第二张卡仅在确认空闲且实验种子独立时使用。日志逐步刷新，保留终点、优化器/RNG 状态和失败记录，运行结束先下载，再 Release 归档并重新下载核验。

近期完成标准：R-03 给出每种任务信息损失发生位置的可复算证据；D-05 给出支持数和新数据是否必要的决定；随后冻结 J-03 或明确不继续 JEPA 的理由。原项目最终完成标准仍是补齐独立历史对照并对策略增益作可信判断，不以保证正收益为条件。
